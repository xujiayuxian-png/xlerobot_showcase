02 / Two grasp routes

换抓取后端，
不用换一套 Demo。

ACT 是主展示路线，centroid 与 GPD 是同级可选的几何后端。三者共用机器人运行栈、标定和任务接口。

同一套机器人基础语音 / 网页入口导航与标定坐标系MoveIt 与本地执行
ROUTE A / HYBRID LEARNING 主 Demo

混合 ACT 抓取

先用视觉定位物体，规划到预抓取位置，再让 ACT 根据腕部图像和关节状态完成局部接触阶段。

  1. RGB-D 粗目标
  2. MoveIt 预抓取
  3. ACT chunks
  4. 本地执行
ACT 学的是局部抓取，不是整段导航与递送。默认后端为 act，Demo 默认物品为羽毛球。
ROUTE B / EXPLICIT GEOMETRY

传统几何顶抓

VLM 找到目标，SAM 2 分割物体，RGB-D 精炼物体与桌面。选择质心顶抓，或使用 GPD 排序后的候选。

  1. VLM + SAM 2
  2. RGB-D 点云
  3. centroid / gpd
  4. MoveIt 执行
GPD 在 GPU 主机的 Ubuntu / WSL2 上运行。失败会明确返回，不静默换成 centroid；目前范围是顶抓，不是通用 6-DoF 抓取。

远程 GPU 提供感知与策略推理，本体执行运动。查看后端实现与运行方式 ↗

03 / Calibration first

把标定，做成能用的工具。

不只给一份配置，还提供采集网页、求解、质量报告、可打印标靶和离线 replay。让自己的机器人有自己的标定。

servo → head-camera → right-handeye
base 可独立测量
→ grasp-alignment → activate → render
标定使用说明 ↗打印 AprilTag 标靶 ↗
  1. 01

    舵机：整组采集，不逐个关节切换

    双从臂与头部按组记录零位和行程，网页显示实时位置与覆盖范围，支持暂停和继续。

    从臂与头部流程已通过真机验收
  2. 02

    头部相机：放好板，自动扫姿态

    网页预览整块 4×4 AprilTag 板，确认后自动转头、等待稳定、采样、求解并保存草稿。

    自动采集与求解已完成真机实验
  3. 03

    右臂手眼：拟合之后，再独立验证

    夹爪固定 Tag 23。20 个姿态拟合并冻结参数，再用 6 个不同姿态验证；网页分别展示残差与逐姿态误差。

    软件流程已通过 · 真机验收待完成

另提供底盘实测与抓取对齐步骤。标定先保存为草稿，完整 bundle 需显式激活。拟合残差、独立视觉/FK 一致性与夹爪实际精度是不同的验证；后续实测精度仍待验收。

05 / Make it yours

想复现？从这里开始。

范围很明确：当前双轮改装 XLeRobot。先对齐参考硬件和环境，再配置自己的设备、标定和场地。

一台机器人，两台计算机。

参考本体

感知与音频
D455、右腕 USB 相机、LD06 风格雷达、麦克风与扬声器
Robot 主机
Ubuntu 24.04 x86_64 · ROS 2 Jazzy
GPU 主机
NVIDIA Ubuntu / WSL2；已使用 RTX 3080 + Ubuntu 24.04 WSL2 验证
视觉语言模型
LM Studio + Qwen3-VL-4B

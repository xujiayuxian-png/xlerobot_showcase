# XLeRobot 家庭服务机器人 — 项目展示页

单文件静态网页（`index.html`，无构建、无框架依赖），展示 XLeRobot
家庭服务机器人的真机闭环 Demo 与工程实践：ROS 2 Jazzy 系统架构、
单臂标定与抓取、ACT 本地安全执行、激光建图与导航、部署与诊断设计。

目标岗位：机器人系统软件 / ROS 2 应用与集成、单臂标定与抓取应用。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

直接双击 `index.html` 也可以。

## 仓库结构

- `index.html` — 展示页全部内容（HTML + CSS + 内联 SVG 架构图）
- `assets/` — 页面引用的图片（整机渲染图、三个演示视频封面）

## 说明

- 页面中的三个演示视频链接至 B 站；源码随教学版开源前暂不公开。
- 真机行为由三个 B 站视频作为主要证据；架构、接口与运行时机制应与当前源码核对。
- 不使用质量门替代实测结果，不使用 Demo 片段推导未统计的成功率。
